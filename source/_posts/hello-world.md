欢迎来到我的博客！本站基于 [Hexo](https://hexo.io/zh-cn/) 搭建，托管在 GitHub Pages 上。

![博客开张](grand-opening.svg)

## 建站记录

- 框架：Hexo 7.x + 默认主题 landscape
- 托管：GitHub Pages（`gh-pages` 分支）
- 写作：Markdown，放在 `source/_posts/` 目录

## 常用命令

``` bash
$ hexo new "文章标题"   # 新建文章
$ hexo server           # 本地预览（http://localhost:4000）
$ hexo clean            # 清除缓存与生成的静态文件
$ hexo deploy           # 生成并发布到 GitHub Pages
```
