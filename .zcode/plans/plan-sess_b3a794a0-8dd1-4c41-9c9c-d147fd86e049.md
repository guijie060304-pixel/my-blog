## 博客优化方案（第一阶段）

### 推荐理由
当前博客是「裸 Hexo」：默认主题最简陋、每次发文要在本地跑 `hexo deploy`、无 RSS/sitemap/搜索。下面三件事互为基础、回报最高，一次做完：

### 1. 更换主题为 Butterfly
- `npm install hexo-theme-butterfly hexo-renderer-pug hexo-renderer-stylus hexo-wordcount --save`
- `_config.yml` 中 `theme: butterfly`；新建站点级主题配置 `_config.butterfly.yml`（覆盖主题默认值，不污染主题目录，便于升级）
- 预设中文站点常用项：导航菜单（首页/归档/标签/分类）、侧栏头像与简介、页脚版权、不蒜子访问量统计、阅读时长

### 2. GitHub Actions 自动部署（告别本地 deploy）
- 新建 `.github/workflows/deploy.yml`：push 到 `main` 后自动 `npm ci → hexo generate → actions/deploy-pages` 发布，使用内置 `GITHUB_TOKEN`，无需任何密钥
- 用之前验证过的 API 令牌把 Pages 构建源从 `gh-pages 分支` 切换为 `GitHub Actions`（PUT /pages, build_type=workflow）
- 以后发文只需 `git push`；`hexo-deployer-git` 配置保留不删，作为本地应急后备手段

### 3. SEO 与发现性基础
- `npm install hexo-generator-feed hexo-generator-sitemap hexo-generator-search --save`
- `_config.yml` 增加 feed（atom.xml）、sitemap（sitemap.xml）配置
- Butterfly 开启本地搜索（local_search），站点内可直接搜文章

### 执行与验证
1. 全部本地装好后 `hexo clean && hexo generate` 确认构建通过、检查 public/ 产物（主题样式、search.xml、atom.xml、sitemap.xml）
2. 本地 `hexo server` 人工确认页面效果后（你可随时看 localhost:4000）
3. commit → push 到 main → 盯 Actions 运行结果 → curl 验证线上页面已切换为新主题

### 第二阶段路线图（本轮不做）
评论系统（giscus，需在 GitHub 上启用 Discussions）、图床/图片管理、自定义域名绑定、搜索引擎收录（Google Search Console/百度站长）、永久链接精简

### 风险与说明
- Butterfly 是中文社区最活跃的主题，文档齐全（butterfly.js.org）；若你更想要 NexT/Fluid，告诉我换哪个，步骤完全相同
- 代理配置不变：Actions 部署在云端构建，不依赖你本机网络；本地 push 仍走已有的 github.com 代理规则
